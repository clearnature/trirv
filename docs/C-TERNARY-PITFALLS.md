# C-TERNARY-PITFALLS —— 三值 C 方言位运算警示录

> 起因（2026-11-26，用户实证捕获）：`x & 255` 在三值容器下 TAND 逐 trit
> min 塌 0（57340224 实测：低 6 trit 全 0 → 结果 0；二进制语义应为 64）。
> 且 **232（<256）TAND = 12 ≠ 232**——「小值无损」不成立，凡多 trit
> 掩码一律与二进制位域语义分道。方法论：**先算后验**——位运算结果先
> 裸返回/printf 单验，再挂进大程序（矩阵乘法本体经裸返回验证完全正确，
> 即此法）。

## 铁律

**C 方言的 `& | ^ ~ << >>` 就是三值本征指令（TAND/TOR/XOR/TNOT/SLL/SRA），
不是二进制位操作。任何二进制位惯用法搬进来都会静默算错——编译通过、
运行不崩、数值错误，比崩溃危险得多。**

## 坑目录与正确替代

| 二进制惯用法 | 三值方言实际行为 | 正确替代 |
|---|---|---|
| `x & 0xFF`（取低字节） | TAND 逐 trit min：掩码 trit 为 0 的位全塌 0 | 取低 tryte = `x % 243`；低 k trit = `x % 3^k` |
| `x & FLAGS`（多旗标位掩码） | 同上，掩码含非 0 trit 的位做 min | **旗标必须 = 3 的幂**（单 trit）：`x & 3^k` ∈ {0, 3^k} 语义成立；多旗标 = 多次单 trit 测试 |
| `c \| 32`（ASCII 大小写折叠） | TOR 逐 trit max ≠ 置 bit5 | 查表（tolower/toupper 表）——musl ctype 查表化动因 |
| `x \|= bit`（置位） | TOR：trit 0→1 可（\|3^k）；0→2 用 `\|2·3^k`；2→1 不可用 `\|` | 清 trit = `%3^k` 去低位 + 高位重组，或 LIT 族 |
| `x ^ x`（清零）/ `a^b^b`（还原） | XOR = (ta+tb)%3 **非自反**：x^x ≠ 0 | 清零 = `x = 0`；还原 = 重算 |
| `x ^ 0xFF`（翻转） | 同上，非自反无翻转语义 | 翻 trit = LIT0（2−t ≡ TNOT）/ LIT1/LIT2 循环后继/前驱 |
| `~0 == -1` | ✓ 恰好成立（2−t 词级 ≡ −1−a，代数巧合非位概念） | 可用，但勿引申「位模式补码」 |
| `1 << 4` | ×3^4 = **81** 非 16 | 移位常数 = 3 的幂次数；乘 2 的幂用 MUL 字面量 |
| `x >> 4` | ÷3^4 向零截断 | 同上 |
| 无符号位模式/逻辑右移/无符号比较 | **§九 无符号视图不存在**（单一带符号域） | 值域思维：字就是带符号 45-trit 整数 |

## 三值旗标正确范式（已实证）

```
int F_APPEND = 3;        /* 单 trit 旗标：3^1 */
int F_CREAT  = 9;        /* 3^2 —— 旗标一律 3 的幂 */
if (flags & F_APPEND)    /* TAND：trit1 ∈ {0,1} 测试语义成立 */
    flags |= F_APPEND;   /* TOR：置该 trit 为 1 */
```

stdio/VDISK/固件旗标面已全量按此范式（批次 6/6.3b 实证）。

## 检测与防护

1. **先算后验**（本录起因方法论）：位运算先裸返回单验。
2. 编译器诊断（挂账）：trirv_cc 对 `x & <非 3^k 字面常量>` 发警告——
   见 TASKS 解析器健壮性批附注。
3. musl 上游文件在三值方言下「编译过但静默算错」= musl_tri 重写层
   存在的理由（ctype 的 `|32` 即首案 → M3 查表化）。
