# 多进制兼容设计与 TDD 计划（2026-11-22 立项）

> 理论基座（用户 2026-11-22 指示）：图灵机本质是状态机——二进制 2 状态 2 输入，
> 三进制 3 状态 3 输入（3²=9 输入组合、3³=27 映射单元）。编译器对多进制的
> 兼容处理 = 编码/解码边界的系统化管理。参考体系：华为三进制真值表专利族
> （Kleene 三值逻辑门 + 文字运算）。

## 0. 状态空间数学（地基）

| 量 | 值 | 推论 |
|---|---|---|
| trit 密度 | log₂3 ≈ 1.585 bit | 三进制符号比 bit 密 58.5% |
| 45-trit 字 | 3^45 ≈ 2^71.3 | 无损容纳 71 bit；72 bit 的最高 1 组合被回绕吞 |
| 20-trit 指令 | 3^20 ≈ 2^31.7 | 指令编码空间 34.9 亿槽（现用 97 条） |
| 二元三值真值表 | 3×3=9 项/运算 | 输入 3² 组合、输出 3 值 |

## 1. 71 位视图提案：**否决记录**（数学否决，省一轮错误实现）

提案：方案 A 从 72 位视图改 71 位（2^71−1 < 3^45 无损）。
**否决理由**：71 位视图只覆盖 81% 的 raw 数域（raw ∈ [2^71, 3^45) 的 19%
不在视图内）。位游标对 raw ≥ 2^71 的输入会产生**高位残留污染**（游标只走
2^70..1，≥2^71 的位从不被剥离）——要干净语义必须每个运算先对操作数做
71 位掩码，成本 ×3。72 位视图 3^45 < 2^72 **全域覆盖输入**（位游标对任意
raw 精确），`~` 的模 3^45 回绕（~0 ≠ −1）是"回绕在 3^45"设计的自洽必然
（文档 §5.1.1 已明示），不是缺陷。**维持 72 位。**

## 2. 现状：四层编码/解码边界（已成体系）

| 层 | 边界 | 机制 | 交付 |
|---|---|---|---|
| L1 数据窄化 | int/short/char ↔ tryte 域 | mod-243/59049/45-trit 全域 | 2026-11-21 拍板落地 |
| L2 位语义 | C 的 &\|^~<<>> ↔ 本征三值 | **直发**（2026-11-22 方言拍板；方案 A 位游标退役） | 双编译器 + 契约重铺 |
| L3 浮点编码 | wasm/C 的 IEEE 位模式 ↔ TF45 | 编译期穿透 | P3/P4 交付 |
| L4 静态数据 | 十进制常量 ↔ base-243 | write45（负数 3^45+v） | B3 交付 |

**ISA 三值逻辑门族（硬件已备、双 VM 已验）**：
`TAND`=Kleene AND（min，假优先）、`TOR`=Kleene OR（max，真优先）、
`TNOT`=Kleene 非（2−aᵢ，0↔2、1→1）、`TMIN`/`TMAX`（同 TAND/TOR 语义等价）、
`TNEG`（3 补码算术负）。**缺口：两个编译器都不能从 C 生成它们。**

## 3. 本轮 TDD 立项：`__tint` 三值逻辑类型（差距 1 → 差距闭合）

### 3.1 类型语义规范（单一真相源——所有用例期望值从这里推导）

- `__tint` = 45-trit 三值逻辑字（9 tryte，同 int 尺寸）；每个 trit ∈ {0,1,2}
  = {假, 不定, 真}（Kleene 体系）。
- **支持**（直发，零模拟）：
  | 运算 | 指令 | 语义 |
  |---|---|---|
  | `x & y` | TAND | 逐 trit min（假优先） |
  | `x \| y` | TOR | 逐 trit max（真优先） |
  | `~x` | TNOT | 逐 trit 2−x |
  | `x == y` / `x != y` | SUB+SEQZ 物化 | 位型全等 |
  | `if (x)` | SUB+SEQZ | x ≠ 全零 |
  | 赋值/传参/返回/取址/数组 | SW/LW | 9-tryte 数据通路同 int |
- **诚实门控（编译期 tcc_error）**：
  - `^`（Kleene 体系无定义；Post 循环加不混入）
  - `< > <= >=`（三值无序——不定态与真假的序不存在）
  - `+ - * / % << >>`（逻辑域无算术）
  - `int ↔ __tint` **隐式转换**（进制语义不同必须显式）
- **显式 cast 允许**：位型原样搬运（`(int)x` / `(__tint)y` 不换编码）。
- 德摩根律在三值 Kleene 体系**成立**（~(x&y) = ~x | ~y，min/max 对偶）
  ——作为代数律锁定用例（与方案 A 的"德摩根不成立"形成体系对照）。

### 3.2 实现点（按层）

| 层 | 文件 | 改动 | 守卫 |

| 类型枚举 | tcc.h | VT_BTYPE 追加 VT_TINT 枚举值（不动既有值） | 全局加（纯新增，零行为变更） |
| 关键字 | tcctok.h | `__tint` token 注册 | `#ifdef TCC_TARGET_TRIRV`（其他目标前端不认，合规） |
