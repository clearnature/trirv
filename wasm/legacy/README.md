# wasm/legacy —— 二进制语义仿真层归档（§九 纯三值拍板前状态）

> 归档原因（2026-11-25，用户指示）：纯三值无回绕拍板（WASM_ROUTE_A §九）
> 将从翻译器中删除二进制语义仿真层，但**后期处理三进制虚拟硬件上的
> 软件编译问题时，需要不停调试与模块重写，需要二进制代码对比处理**；
> 且与既定规划「底层二进制硬件暴露白名单」（VM 边界，另立项）直接
> 相关——本归档 = 那个白名单子系统的种子参考实现。

## 使用纪律

- 本目录**不参与任何构建/回归**（无 suite 引用）；改动主翻译器时**勿同步改这里**——它冻结在 `982cf1b` 快照，作为历史对照锚点。
- 未来「VM 边界二进制暴露白名单」（另立项）立项时：本目录的 wrap/位走查/digit 拆装 = 该子系统的算法底稿（届时按白名单边界重新审查哪些仿真允许出现在虚拟层）。
- 差分对拍流程（预估）：三值模块输出 X → 同输入喂 oracle 得 Y → X≠Y 时先查算法改写是否引入语义漂移，再查翻译器 bug。
