## 当前实验

### p-trit / 三值热力学修复退火（`p_trit_lab.py`）

- **p-trit 单元**：三态涨落比特——噪声三电平量化 → trit ∈ {0,1,2}
  （对应硬件期的三值熵源空白点，HW-TERNARY-NOTES §四）
- **q=3 冲突修复退火**：图 3-着色 = q=3 Potts 能量极小化
  （E = 相邻同色对数）；热噪声驱动冲突修复循环
- **TriRV VM 内核**：退火循环以 wasm 方言直发（REM/ADD/LBU/SB 原生
  1:1），噪声从线性内存 tryte 流读取——**三值热力学计算内核跑在三值
  虚拟硬件上**，与 Python 参考逐位对拍
